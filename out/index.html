01 — Recognition & performance
Caption latency0.5–2.5 sDepends on the speed–quality setting and source audio.
Word error rate (WER)1.4–5%Depends on the speed–quality setting and audio conditions. Lower is better.
Operating selectorSpeed priority / quality priorityBalances caption response time against recognition quality.
Language & layoutHebrew speech recognition / right-to-left captions
02 — System & reliability
System typeStandalone physical appliance
ProcessingLocal, on-device AI speech recognition
Operating duty24/7Designed for continuous studio operation.
Internet / cloudNot required for live captioningOffline operation is independent of internet disruptions and cloud outages.
03 — Input / output & control
Audio inputSpeech feed from a mixer or compatible audio interface
Caption outputBrowser-based visual overlay / local viewer URL
Production integrationOBS Browser Source demo workflowOther production hosts assessed per installation.
Operator controlLocal session and caption-output controlThe production team controls when captions go on air.
04 — Technology & installation notes
Operating principleLocal AI converts live Hebrew audio into text. The system formats right-to-left captions and delivers a visual layer to the production workflow.
ValidationPerformance, audio routing, hardware environment and recovery procedures are assessed with representative studio material.
Integration scopeVideo remains in the existing production chain. SDI, genlock and embedded closed captions require a separate assessment.
